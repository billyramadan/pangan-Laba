# Presentasi Bimbingan — PanganLaba (Poin Singkat)

Format: 5 menit presentasi + tanya jawab. Baca poin, jangan membaca lengkap.

---

## 1. Pembukaan (30 detik)

> "Selamat pagi/siang, Bapak/Ibu. Saya akan mempresentasikan perkembangan proyek tugas akhir saya: PanganLaba, aplikasi web untuk membantu UMKM kuliner Kota Depok."

---

## 2. Masalah (1 menit)

- Harga bahan pangan fluktuatif → UMKM kuliner kesulitan merencanakan belanja & menetapkan harga jual.
- Masalah nyata: modal per porsi jarang dihitung, laba tidak terukur.

## 3. Solusi & Model Income (2 menit)

**Aplikasi:**
- Prediksi harga komoditas (LSTM/GRU) 7 hari ke depan.
- Kalkulator laba otomatis: modal per porsi, laba bersih, margin, titik impas.
- Saran belanja beli/tunda.

**Model income (sesuai arahan):**
- Trial 7 hari gratis → langganan paket berbayar (Starter/Pro/Enterprise). 
- Pembayaran manual (diverifikasi) atau Xendit otomatis.
- Akses terkunci jika belum bayar setelah trial.

## 4. Rencana Uji Coba ke UMKM (1 menit)

- Target: 6–8 UMKM kuliner Kota Depok.
- Metode: wawancara semi-terstruktur + demo aplikasi.
- Yang diukur: (1) masalah nyata, (2) kemauan pakai, (3) kesediaan bayar.
- Output: bukti lapangan untuk menguatkan manfaat & validasi model income.

## 5. Penutup (30 detik)

> "Jadi intinya: aplikasi ini menggabungkan model machine learning yang diuji jujur, aplikasi yang bermanfaat untuk UMKM, dan model income yang sedang saya uji lapangan. Saya mohon arahan untuk langkah selanjutnya, terutama untuk uji coba UMKM."

---

## Ringkasan buat Tanya Jawab

| Pertanyaan | Jawaban |
|---|---|
| Model income? | Trial 7 hari → paket berbayar (manual/Xendit). |
| Bukti mau bayar? | Sedang diuji coba ke UMKM — diukur kesediaan bayar. |
| Manfaat UMKM? | Laba otomatis + prediksi harga untuk keputusan belanja. |
| Kok fitur eksternal nurunin akurasi? | Temuan jujur; didiskusikan, bukan disembunyikan. |
| Ini skripsi ML atau aplikasi? | Keduanya — riset aplikatif. |
